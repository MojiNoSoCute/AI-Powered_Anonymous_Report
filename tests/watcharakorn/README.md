# ชุดการทดสอบอัตโนมัติ: ผู้ทดสอบ วัชรากร (watcharakorn)

ชุดทดสอบนี้ครอบคลุมการทำงานของ **2 โมดูลหลัก** รวมทั้งหมด **30 Test Cases**:
1. **Module 1: การส่งรายงานเบาะแสลับ (Anonymous Report Submission - FR-SUB)**: TC-001 ถึง TC-021
2. **Module 2: ระบบวิเคราะห์อัจฉริยะด้วย AI (AI Smart Assistant Analysis - FR-AI)**: TC-022 ถึง TC-030

---

## 🚀 วิธีการรันชุดทดสอบของวัชรากร

```bash
# รันการทดสอบทั้งหมดของวัชรากร (30 Cases)
pytest tests/watcharakorn/ -v

# รันเฉพาะโมดูลการส่งรายงาน (Submission)
pytest tests/watcharakorn/test_sub_module.py -v

# รันเฉพาะโมดูล AI Smart Assistant
pytest tests/watcharakorn/test_ai_module.py -v
```
